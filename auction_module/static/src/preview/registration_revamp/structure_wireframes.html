Proposed structure

Keep every existing field. Change the page architecture: compact tournament header, three steps, no marketing sidebar. First screen is the form — that is what Instagram traffic needs.

What is wrong now

  • Hero copy, roster banner, six trust cards, then a second “Registration” strip — four layers before the first field
  • Sidebar (Why / Privacy / Fair) repeats the trust strip and does not help submit
  • One long page of 5–6 sections; mobile users accordion-hunt
  • Instagram first fold never reaches photo + name

What to change

  • Header is compact: logo, name, date, venue, roster count
  • Tournament poster stays — desktop sticky rail, mobile thumbnail (tap to open)
  • Three steps: Player → Game → Pay & submit
  • Trust becomes one line under the button
